# PositionTracker: Plan Series

**Spec:** `docs/superpowers/specs/2026-10-30-possition-tracker-design.md`

The spec covers several independent subsystems, so it is implemented as a series of plans. Each plan ends with software that runs and is tested on its own.

| # | Plan | Delivers | Depends on |
|---|---|---|---|
| 1 | **Core tracking engine** (`2026-10-30-plan-1-core-tracking-engine.md`, DONE on branch `feat/core-engine`, ledger: `2026-10-30-plan-1-execution-ledger.md`) | GPX course, map matching, laps, metrics, ETA, ranking, sector colours, alarm states, ingest API, live views and SignalR, demo simulator | none |
| 2 | **Accounts, events, registration** (`2026-10-30-plan-2-accounts-registration.md`, DONE on branch `feat/accounts-registration`; Task 8 CSV import skipped; open manual gates: OwnTracks field test, email deliverability results) | PostgreSQL persistence (EF Core), organizer account and email sign-in, event creation, participant registration by the organizer, invitation emails from the own SMTP server (deliverability check first), confirmation, nickname and gender, token issue and re-issue | 1 |
| 3 | **Web app shell, i18n, themes** (DONE: `web/`, plans 3-5 were built together without separate plan files) (decision 2026-10-31: no PWA tracker; the participant screens are limited to join, consent and OwnTracks setup) | React + Vite PWA, Slovak/English strings, light/dark theme tokens from the mockups, routing, API client, service worker | 1 |
| 4 | **Participant and organizer UIs** | Join flow and OwnTracks setup page (QR/deep link), organizer dashboard and registration pages, GPX upload (the PWA live screen with offline queue is dropped; OwnTracks tracks in the background) | 2, 3 |
| 5 | **Spectator UI, deployment, pilot** | Public spectator page, in-page finish alert, deployment to the home server behind the reverse proxy with HTTPS, rate limiting and hardening, pilot checklist | 2, 3, 4 |

Plans 2 to 5 are written after Plan 1 is reviewed, because their interfaces depend on what Plan 1 actually produces.

## Status 2026-10-31

Plans 1 and 2 are done; Plans 3-5 were implemented directly (no separate plan files): `web/` (React + Vite + TS, SK/EN, light/dark; organizer, participant and
spectator pages; vitest), the SPA served by the API, security headers and forwarded-header support (`Proxy:*`), `Dockerfile`, `docker-compose.prod.yml` and
`docs/ops/deployment.md` with the pilot checklist. **Not deployed.** Open manual gates: OwnTracks field test, email deliverability results and mailbox password
rotation, the reverse-proxy/Cloudflare Tunnel setup, the rehearsal event (see the checklist).
